# 生产页面回归

`npm ci` 后执行 `npm run build`，再执行 `npm run test:production`。

测试直接启动 `out/`，先核对构建指纹与当前 Git 源码一致。使用独立临时浏览器上下文和合成材料，不读取日常浏览器配置或真实 API 密钥，不产生 AI 费用。测试端口默认 3177；已占用时明确失败，不接管或关闭已有服务。

Windows 默认使用已安装的 Edge；其他系统先执行 `npx playwright-core install --with-deps chromium`。可用 `VERNIQ_BROWSER_PATH` 指定浏览器，用 `VERNIQ_TEST_PORT` 指定空闲端口。

- `storage-faults.mjs`：主数据优先、配额错误、恢复缓存同时不可用、暂停后再次保存、下载内存恢复副本、导航保护、附属时间缓存失败。
- `import-ui.mjs`：输入、真实 TXT 导入、四种导入入口、中英文、小屏排版。
- `documents.mjs`：真实 PDF（包括中文 CID 字体）、DOCX、TXT、Markdown、HTML；扫描、受保护及损坏文件错误提示。`fixtures/documents/` 全为本项目生成的合成测试材料，不含用户材料。
- `workbench.mjs`：受控协议响应下的模型配置、文章重点、笔记反馈、追问、多材料写作、修改、草稿恢复、长文编辑和左右布局。
- `learning-loop.mjs`：真实鼠标划词、本地双语词典、词汇保存、先回忆再评分、纠错、FSRS 排期、刷新恢复与实际下载的 Anki TSV。设备语音只验证语言选择，不冒充听音验收。
- `setup-help.mjs`：中英文的语音安装帮助、无匹配语音与浏览器不支持的区别、展开后的小屏边界，以及 AI 配置说明。语音能力由模拟引擎提供，不冒充系统安装或听音验收。
- `card.mjs`：实际下载 PNG 并检查边缘像素、图片拖拽缩放与预览一致、三种比例、署名、构图保存恢复及英文小屏。
- `responsive.mjs`：两种学习模式、8 个页面、6 种宽度，包含用户报告的 1257×704、设备缩放 2.25，检查横向越界和长错误文本。

结果与截图写入忽略的 `build/`。协议模拟测试不能证明真实供应商可用，也不能替代桌面安装包验收；真实服务测试应另行记录且不能把密钥写进结果。
